Backup & Restore

Cadangkan keseluruhan data aplikasi (database + seluruh file dokumen/surat/RPS) ke satu file, atau pulihkan dari cadangan sebelumnya.

💾 Backup Sekarang

Backup Lengkap mencadangkan database beserta seluruh file fisik yang tersimpan di luar database — dokumen (Document Center), bukti akreditasi, dokumen kerjasama, RPS, dokumen RPL, arsip surat keluar, dan logo institusi — jadi satu file .zip siap dipindahkan ke komputer lain. Aman dijalankan kapan saja, termasuk saat aplikasi sedang dipakai.

⚠️ Restore dari File

Menimpa seluruh data saat ini dengan isi file yang diunggah — untuk file .zip (Backup Lengkap), folder dokumen/surat/RPS ikut dipulihkan. Data saat ini otomatis dicadangkan lengkap dulu sebelum ditimpa. Anda akan diminta login ulang setelah restore selesai.

🗑️ Reset Total Data

Mengosongkan seluruh data aplikasi (mahasiswa, dosen, kurikulum, nilai, seluruh modul) dan mengembalikannya persis ke kondisi baru diinstal — Anda akan diminta membuat ulang akun admin setelahnya. Berkas yang sudah diunggah (dokumen, RPS, dst.) tidak ikut terhapus dari folder data, hanya catatannya di database yang hilang. Data saat ini otomatis dicadangkan lengkap dulu sebelum dikosongkan, jadi tetap bisa dipulihkan lewat Restore di atas kalau ternyata keliru.

📁 Riwayat Backup

Tiap backup ditandai kode tahun ajaran yang sedang "Berjalan" saat backup itu dibuat — dipakai untuk menyaring riwayat, BUKAN untuk memisah/mengekspor data per tahun (backup tetap mencadangkan keseluruhan data aplikasi).
